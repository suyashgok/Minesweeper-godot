Minesweeper (Godot 4.6, C#)

A mouse-driven Minesweeper game built in Godot Engine with C# as a
Computer Graphics elective project. It started as a console prototype
with keyboard input and grew into a full GUI game.

Features
- Main menu and game scene with scene switching
- Left-click to reveal, right-click to flag
- Safe first click: mines are placed after the first click, away from it
- Recursive flood-fill reveal for empty areas
- Win and loss detection, with all mines shown on a loss
- Play Again and Main Menu buttons
- Resolution scaling: 1920x1080 design, canvas_items stretch, keep aspect

How to run
1. Install Godot 4.6 (.NET / Mono version)
2. Open the project folder in Godot
3. Press F5
